# ETNARA Website

Sitio institucional público de ETNARA Care.

## Objetivo
Presentar ETNARA como plataforma B2B para agencias de cuidado y establecimientos de adultos mayores, separada de la aplicación operacional.

## Estructura
- Sitio estático, responsive y sin dependencias de build.
- `index.html` — contenido y estructura.
- `styles.css` — identidad visual y responsive.
- `script.js` — navegación móvil.

La aplicación ETNARA Care continúa separada de este repositorio.
